# Academia Villarejo — Web

Propuesta de web premium y minimalista para **Academia Villarejo** (Camino de Ronda 212, Granada).

## Archivos
- `index.html` — página única (HTML + CSS + JS inline, sin frameworks ni dependencias externas).
- `fonts/` — tipografías autoalojadas (Instrument Serif, Geist, Geist Mono · licencia SIL OFL). Sin Google Fonts: más rápido y sin enviar datos a terceros (RGPD).
- `og.png` — imagen para compartir en WhatsApp/redes (1200×630).
- `favicon.svg`, `robots.txt`, `sitemap.xml`.

## Verla en local
```bash
python3 -m http.server 8000   # y abrir http://localhost:8000
```
