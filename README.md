# Academia Villarejo — Web

Propuesta de web premium y minimalista para **Academia Villarejo** (Camino de Ronda 212, Granada).

- `index.html`: página única autocontenida (HTML + CSS + JS inline, sin frameworks).
- Secciones: hero, niveles, método, Selectividad/PAU, dirección, opiniones, FAQ, contacto (formulario → WhatsApp) y footer.
- Rendimiento: sin dependencias salvo Google Fonts (`display=swap`), animaciones solo con `transform`/`opacity`, respeta `prefers-reduced-motion`.
- SEO: metadatos, Open Graph y JSON-LD `EducationalOrganization`.

Abrir `index.html` en el navegador para verla.
